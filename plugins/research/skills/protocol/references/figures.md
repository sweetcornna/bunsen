# 作图与图表报告

图用来解释数据，不替数据挑故事。

- 数据忠实。不要截断坐标轴夸大差异；确需局部放大时明确标注并给全范围参照。异常点不能悄悄删除或平滑；写清排除、平滑方法，保留原始数据与未处理对照。
- 信息齐全。坐标轴写变量和单位；注明样本量、重复次数、误差条或区间的含义及算法（例如按何种独立单位 bootstrap），不要让标准差和置信区间混用。
- 比较一致。同一变量跨图用同一种颜色、同一方向和命名；适合直接比较的图用一致尺度。颜色之外保留线型或文字，灰度下也能区分。
- 来源可追。保存作图脚本，用 `rk run <ID> --explore --in <数据> --out <图目录> -- <作图命令>`；属于确认性分析时改用已提交的 `--prereg <规则>`。图和表进入 `outputs.json`，结果页链接实际文件并标运行 ID；不手改图上数字。
- 出图后打开检查。看裁切、重叠、图例、坐标、单位、区间及数字；对照数据与输出清单。缺记录就补跑，不把旧图冒充本次产物。

审计员用核对模式查图题与标注是否符合原始数据、图的当前哈希是否在输出清单；查不到就明确写出，不凭观感判通过。
